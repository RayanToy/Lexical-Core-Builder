# Lexical Core Builder

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![NLP](https://img.shields.io/badge/NLP-Educational%20Linguistics-orange.svg)](https://github.com)

Инструмент для автоматического построения лексических ядер учебных текстов с алгоритмом межклассного наследования и расчётом коэффициента стабильности Жуайна.

Проект разработан для корпуса учебников российских школ 1–11 классов по всем предметам, но архитектура универсальна и применима к любому образовательному корпусу с иерархической структурой сложности.

---

## Описание

Инструмент решает задачу автоматического определения **лексического ядра** — минимального словарного запаса, необходимого для понимания учебных текстов по предмету и классу.

Основные сценарии применения:

- **Педагогический дизайн**: определение словарного минимума для учебных материалов
- **Лингводидактика**: анализ лексической сложности текстов по классам
- **Учебное книгоиздание**: контроль терминологической нагрузки по годам обучения
- **Корпусная лингвистика**: исследование образовательного дискурса

### Основные возможности

- **Межклассное наследование** — ядро класса N автоматически включает ядра классов 1..N−1
- **Коэффициент Жуайна** — метрика стабильности частотности слова по корпусу учебников (0–100)
- **Двойная фильтрация** — отбор по покрытию (% учебников) и нормализованной частотности
- **Интеграция общеупотребительной лексики** — дополнение ядра словами из внеклассного чтения
- **Кумулятивные ALL-словари** — сводные таблицы по всем предметам с накоплением по классам
- **Специальная обработка биологии** — дополнение терминами из ОкМ/Экологии младших классов
- **Пакетная обработка** — автоматическая обработка всех классов и предметов
- **Подробные метрики** — НЧ по учебникам, покрытие, источник слова (предмет/внеклассная)

## Технологический стек

- **pandas, numpy** — ETL Excel-файлов, агрегация, статистика
- **openpyxl** — чтение и запись `.xlsx`
- **PyYAML** — загрузка настроек из `config.yaml`
- **pathlib** — кросс-платформенная работа с путями (Windows / Linux)
- **pytest, pytest-cov** — unit-тесты и покрытие кода

**Ключевое решение**: модульная архитектура с разделением ответственности позволяет легко тестировать и модифицировать каждый компонент алгоритма независимо.

## Установка

```bash
git clone https://github.com/YOUR-USERNAME/lexical-core-builder.git
cd lexical-core-builder
```

Создаём виртуальное окружение:

```bash
python -m venv .venv
```

Активируем:

```bash
# Windows
.venv\Scripts\activate

# Linux / Mac
source .venv/bin/activate
```

Устанавливаем зависимости:

```bash
pip install -r requirements.txt
```

## Быстрый старт

### 1. Настройка конфигурации

Копируем шаблон:

```bash
cp config.yaml.example config.yaml
```

Открываем `config.yaml` и указываем пути к данным:

```yaml
base_dir: "/path/to/your/lexical_lists"
common_fallback_dir: "/path/to/your/fallback_lists"
common_books_dir: "/path/to/your/books_lists"
coverage_threshold: 70
norm_freq_threshold: 20
common_kv_min_threshold: 7
```

Проверяем конфигурацию:

```bash
python -c "from src.config import load_config; load_config('config.yaml')"
```

python -m src.main --config config.yaml

## Формат выходных данных

### Предметное ядро

Файл находится по пути:

```
предмет/Общий частотный список/Лексическое ядро класс предмет.xlsx
```

Столбцы файла:

| Столбец | Описание |
|---|---|
| Слово | Лемма |
| Предметная область | Предмет или Внеклассная литература |
| КВ | Абсолютная частота по предмету |
| НЧ | Нормализованная частотность на 1 млн слов |
| Покрытие % | Доля учебников содержащих слово |
| Коэффициент Жуайна | Стабильность частоты по учебникам от 0 до 100 |
| КВ Внеклассная литература | Частота в корпусе внеклассного чтения |
| КВ_учебник | Абсолютная частота в конкретном учебнике |
| НЧ_учебник | Нормализованная частота в конкретном учебнике |

### Кумулятивный ALL

Файл находится по пути:

```
CombinedLexicalCores/класс/Лексическое ядро класс ALL.xlsx
```

Столбцы файла:

| Столбец | Описание |
|---|---|
| Слово | Лемма |
| Предметные области | Список предметов через запятую |
| КВ сумма слов | Суммарная частота по всем предметам |
| Количество учебников | Число уникальных учебников со словом |
| Появился в классе | Минимальный класс вхождения в ядро |
| КВ Bi, КВ Mt | Частота по каждому предмету |

Таблица отсортирована по убыванию суммарной частоты.

## Алгоритм работы

### 1. Базовое ядро предмета

Слово включается в базовое ядро если одновременно выполнены два условия:

```
Покрытие >= coverage_threshold   (по умолчанию 70%)
НЧ       >= norm_freq_threshold  (по умолчанию 20 на 1 млн слов)
```

### 2. Коэффициент Жуайна

Мера стабильности частотности слова по корпусу учебников:

```
J = 100 * (1 - sigma / (mu * sqrt(n - 1)))

sigma  -- стандартное отклонение НЧ по учебникам (ddof=1)
mu     -- среднее НЧ по учебникам
n      -- количество учебников
```

Интерпретация значений:

```
J близко к 100  ->  слово встречается равномерно во всех учебниках
J близко к 0    ->  слово сконцентрировано в отдельных учебниках
```

### 3. Межклассное наследование

```
Ядро[N] = БазовоеЯдро[N] + Ядро[N-1] + ОбщеупотрЛексика[N] + Extra[N]
```

где `Extra[N]` — дополнительные слова, например OkM и Ec для биологии.

### 4. Обработка общеупотребительной лексики

Источники данных по приоритету:

```
1. base_dir/N класс списки/Общеупотребительная лексика/
2. common_fallback_dir/Общий частотный список N класс.xlsx
3. Суммирование по книгам из common_books_dir/N класс/
```

Фильтр: КВ больше common_kv_min_threshold (по умолчанию 7).

Важно: общие списки внеклассной уже кумулятивны, поэтому не суммируются между классами.

### 5. Кумулятивный ALL

На каждом классе выполняется последовательно:

```
1. Агрегируются предметные ядра текущего класса
2. Добавляется общеупотребительная лексика текущего класса
3. Объединяется с накопленным состоянием предыдущих классов
4. Сохраняется сводный файл ALL
```

## Параметры конфигурации

Все параметры задаются в `config.yaml`.

Пороги базового ядра:

```yaml
coverage_threshold: 70
norm_freq_threshold: 20
```

Общеупотребительная лексика:

```yaml
common_kv_min_threshold: 7
add_common_nf_column: false
```

Нормализация:

```yaml
norm_base: 1000000
```

Разрешённые предметы:

```yaml
allowed_subjects:
  - "Al"
  - "Bi"
  - "Ch"
  - "Ge"
  - "Hs"
  - "Mt"
  - "Ph"
  - "R"
```

Исключённые блоки:

```yaml
excluded_block_names:
  - "Гуманитарный блок"
  - "Естественно-научный блок"
  - "Математический блок"
```

## Производительность

| Задача | Время | Объём |
|---|---|---|
| Подготовка Bi-дополнения | 5-15 мин | OkM/Ec 2-4 классы |
| Один предмет | 30-90 сек | 3-5 учебников |
| Один класс 8 предметов | 5-10 мин | 25 учебников |
| Полный pipeline 5 классов | 30-60 мин | 200 файлов |

Тестировалось на Intel Core i5, 16 GB RAM, SSD.

Узкие места:

- Загрузка больших Excel-файлов через pandas.read_excel
- Множественные операции с DataFrame
- Дисковый I/O при сохранении результатов

Оптимизации:

- Кэширование общеупотребительной лексики
- Ленивая загрузка конфигурации
- Переиспользование pandas DataFrame

## Известные ограничения

- Требует строгую структуру папок вида N класс списки
- Ожидает конкретные имена столбцов в Excel: Слово, Сумма слов, Нормализованная частотность
- Число токенов учебника извлекается из имени файла: учебник_46852.xlsx
- Список предметов задаётся в allowed_subjects в конфигурации
- Нет проверки на повреждённые Excel-файлы
- Коэффициент Жуайна не определён для одного учебника, возвращает 0.0

## Troubleshooting

### Не найдено ни одной директории классов

Сообщение об ошибке:

```
Не найдено ни одной директории классов в base_dir.
Проверьте путь: /your/path
Ожидаемые папки: 5 класс списки, 6 класс списки, и т.д.
```

Решение: проверьте точность пути base_dir и наличие папок в формате N класс списки.

### Отсутствуют обязательные столбцы

Сообщение об ошибке:

```
ValueError: Файл ... не содержит обязательных столбцов:
['Нормализованная частотность']
```

Решение: проверьте наличие столбцов в Excel-файле:

- Слово
- Сумма слов
- Нормализованная частотность (или Нормализованная частота)

### Нет пригодных учебников для анализа

Сообщение об ошибке:

```
[Класс 5, Bi] Учебников: найдено 3, использовано 0, пропущено 3
[Класс 5, Bi] Нет пригодных учебников для анализа -> пропуск
```

Возможные причины:

- Имя файла не содержит число токенов, ожидается формат учебник_46852.xlsx
- Файл повреждён или имеет неправильную структуру
- Отсутствуют столбцы Слово или Сумма слов

### Ошибка парсинга YAML

Сообщение об ошибке:

```
yaml.scanner.ScannerError: while scanning a double-quoted scalar
expected escape sequence of 8 hexadecimal numbers, but found 's'
```

Решение: используйте прямые слэши или двойные обратные слэши в путях:

```yaml
# Неправильно
base_dir: "C:\Users\spot2\Desktop"

# Правильно
base_dir: "C:\\Users\\spot2\\Desktop"

# Тоже правильно
base_dir: "C:/Users/spot2/Desktop"
```
